------------------------------------------------------------
FIX DATABASE (Clean Demo)
------------------------------------------------------------
IMPORTANT: Never delete the database while the server is running.

1. Go to Terminal 1 and press Ctrl+C to stop the server.
2. Run:
   Remove-Item data\timeos.db
3. Restart the server:
   python server.py

The database and table are recreated automatically on startup.


------------------------------------------------------------
RECONNECT BROWSER
------------------------------------------------------------
Refresh with: Ctrl + Shift + R
Or reopen:    http://localhost:3000/alexa_sim.html


------------------------------------------------------------
TROUBLESHOOTING
------------------------------------------------------------

Problem: "Failed to fetch" in browser
Fix:     Terminal 1 server is not running. Restart it:
         python server.py
         Then refresh browser with Ctrl + Shift + R

Problem: "no such table: events"
Fix:     Stop server (Ctrl+C), then restart:
         python server.py

Problem: "Invalid Host header"
Fix:     Make sure this line is in server.py inside FastMCP(...):
         transport_security=TransportSecuritySettings(
             enable_dns_rebinding_protection=False
         )
         Then restart the server.

Problem: ModuleNotFoundError: mcp.server.fastmcp
Fix:     pip install "mcp<2"

Problem: uvicorn not found
Fix:     pip install uvicorn

Problem: Port 3000 already in use
Fix:     python -m http.server 3001
         Then open http://localhost:3001/alexa_sim.html

Problem: Port 8765 already in use
Fix:     Stop the old server (Ctrl+C in Terminal 1), then:
         python server.py

Problem: cloudflared not found
Fix:     Use .\cloudflared.exe (with the .\ prefix)
